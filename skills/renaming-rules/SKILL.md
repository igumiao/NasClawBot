# 影视文件整理规范

## 📁 分类目录结构

整理前先确保 `{root}` 下存在以下目录（不存在则用 `create_directory` 创建）：

```
{root}/
├── 电影/       ← 单部电影
├── 剧集/       ← 多季多集电视剧
├── 动漫/       ← 动画番剧
├── 综艺/       ← 综艺节目
├── 纪录片/     ← 纪录片
├── 其他/       ← 无法识别的资源，留待人工
├── 未整理/     ← 待处理的原始文件（唯一扫描来源）
└── trash/      ← 空目录和废弃文件，用户手动清理
```

---

## 🎬 电影（单层结构）

| 层级 | 格式 | 示例 |
|------|------|------|
| 文件夹 | `中文名.EnglishName.年份` | `黑客帝国.The.Matrix.1999` |
| 文件 | `中文名.EnglishName.年份.扩展名` | `黑客帝国.The.Matrix.1999.mkv` |

文件夹内字幕、nfo 等附属文件统一使用相同前缀。

---

## 📺 剧集/动漫/综艺/纪录片（三层结构）

| 层级 | 格式 | 示例 |
|------|------|------|
| 祖父级 | `中文名.EnglishName.年份` | `绝命毒师.Breaking.Bad.2008` |
| 父级 | `Season XX`（两位数字） | `Season 01` |
| 文件 | `中文名.EnglishName.SXXEXX.扩展名` | `绝命毒师.Breaking.Bad.S01E01.mkv` |

- 季度文件夹固定英文 `Season 01` / `Season 02` …
- 集数格式 `S01E01` 或 `S01.E01` 均可
- 单季资源同样用此结构（仍有 Season 01 层）

---

## 📋 整理流程

0. **初始化** — 检查 `{root}` 下分类目录是否齐全，缺失则用 `create_directory` 创建
1. **扫描** — `list_directory` 或 `directory_tree` 查看 `未整理/`
2. **识别** — 从文件名提取：中英文名、年份（`19xx/20xx`）、季号（`S01`、`Season 1`）、集号（`E01`）
3. **判断类型**：
   - 有季/集标记 → 据内容归入 剧集/动漫/综艺/纪录片
   - 无季/集 → 电影
   - 不确定 → 用 TMDB 搜索辅助
   - **TMDB 查不到明确结果时**，按以下顺序尝试获取信息：
     1. **Tavily 网络搜索** — 用 `tavily_search` 搜索该影视作品的中英文名、年份、类型等信息。可分别用中文和英文关键词搜索以交叉验证。
     2. **LLM 自有知识** — 如果 Tavily 也查不到明确结果，可以依赖你（LLM）对该影视作品的训练知识来推断正确的中文名、英文名、年份和分类。LLM 的知识通常覆盖广泛的影视作品信息。
     3. **以上都失败** — 不论有无季/集标记，一律移入 `其他/` 待人工处理。
       原则是「查无实据就存疑」——宁可放 `其他/`，也不自作主张放入 电影/剧集/动漫 等已整理目录。
4. **创建结构** — 在对应分类目录下创建规范的文件夹和 Season 目录
5. **移动前检查上传状态** — 在执行 `move_file` 之前：
   - 用 `qb_get_torrent` 查找对应的种子（通过 `qb_hash` 参数），检查其状态是否为 `uploading` 或 `seeding`（即种子正在做种上传）
   - 如果种子正在上传（qb 会锁住文件导致移动失败），先用 `qb_control_torrent` 执行 `pause` 暂停种子
   - 暂停成功后再执行文件移动
   - **注意**：只允许 `pause` 操作，不要执行 `delete`、`resume` 等其他操作
6. **重命名并移动** — `move_file` 将文件移入新位置并改名
7. **清理** — 原位置空目录移入 `trash/`

## ⚠️ 要点

- 只处理 `未整理/`，不碰已整理好的目录
- 移动前用 `get_file_info` 确认源文件存在
- **移动前必须检查种子上传状态**：用 `qb_get_torrent` 查看种子是否在 uploading/seeding，如在则先用 `qb_control_torrent` pause 暂停后再移动
- 优先用 `tmdb_search` / `tmdb_details` 获取准确命名，不要猜
- TMDB 查不到时，用 `tavily_search` 网络搜索；网络也查不到时，可用 LLM 自有知识判断
- **TMDB + Tavily + LLM 知识都查不到的资源 = 存疑，放 `其他/`。禁止默认当成电影或剧集直接整理。**
