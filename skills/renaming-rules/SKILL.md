# 影视文件重命名与目录结构规范

## 📁 分类目录结构

```
{root}/
├── 电影/       ← 🎬 单部电影
├── 剧集/       ← 📺 多季多集电视剧
├── 动漫/       ← 🎌 动画番剧
├── 综艺/       ← 🎤 综艺节目
├── 纪录片/     ← 📖 纪录片
├── 未整理/     ← 📂 待整理的原始文件
└── trash/      ← 🗑️ 整理后的残余空目录/垃圾
```

- `{root}` 为 filesystem MCP 允许访问的根目录
- 整理成功后的文件放入对应分类目录
- `未整理/` 是唯一需要 Agent 扫描的来源目录
- `trash/` 收集空目录和废弃文件，由用户手动清理

---

## 🎬 电影命名规则

**层级：** 单层（文件夹即存放层）

| 层级 | 格式 | 示例 |
|------|------|------|
| 文件夹 | `中文名.EnglishName.年份` | `黑客帝国.The.Matrix.1999` |
| 文件 | `中文名.EnglishName.年份.扩展名` | `黑客帝国.The.Matrix.1999.mkv` |

**说明：** 文件夹内所有文件（视频、字幕、nfo 等）统一使用以上前缀命名。

**示例目录树：**
```
电影/黑客帝国.The.Matrix.1999/
├── 黑客帝国.The.Matrix.1999.mkv
├── 黑客帝国.The.Matrix.1999.chs.srt
└── 黑客帝国.The.Matrix.1999.nfo
```

---

## 📺 剧集/动漫/综艺/纪录片 命名规则（多季资源）

**层级：** 祖父级 → 父级(按季) → 文件

| 层级 | 格式 | 示例 |
|------|------|------|
| 祖父级文件夹 | `中文名.EnglishName.年份` | `绝命毒师.Breaking.Bad.2008` |
| 父级文件夹 | `Season XX` | `Season 01`、`Season 02` |
| 文件 | `中文名.EnglishName.SXXEXX.扩展名` | `绝命毒师.Breaking.Bad.S01E01.mkv` |

**说明：**
- 季度文件夹固定英文 `Season 01` / `Season 02` …（两位数字）
- 集数格式支持 `S01E01` 或 `S01.E01`
- 动漫、综艺、纪录片同样按此结构处理

**示例目录树：**
```
剧集/绝命毒师.Breaking.Bad.2008/
├── Season 01/
│   ├── 绝命毒师.Breaking.Bad.S01E01.mkv
│   ├── 绝命毒师.Breaking.Bad.S01E02.mkv
│   └── 绝命毒师.Breaking.Bad.S01E01.chs.srt
├── Season 02/
│   ├── 绝命毒师.Breaking.Bad.S02E01.mkv
│   └── 绝命毒师.Breaking.Bad.S02E02.mkv
```

**补充说明：** 单季单集资源（如某动漫只有一季）也使用此结构：
```
动漫/某番剧.Name.2024/
└── Season 01/
    └── 某番剧.Name.S01E01.mkv
```

## 🗑️ 垃圾清理规则

- 整理完成后产生的空目录 → 移入 `trash/`
- 无用文件（如 `*.txt`、`*.url`、`*.html` 等无关文件）→ 移入 `trash/`
- `trash/` 由用户手动定期清理，Agent 不主动删除

---

## 📋 整理流程

每次整理按以下步骤执行：

1. **扫描** — 使用 `list_directory` 或 `directory_tree` 查看 `{root}/未整理/` 下的所有文件和文件夹
2. **识别** — 从文件名/文件夹名中提取关键信息：
   - 中文名、英文名
   - 年份（`19xx` / `20xx`）
   - 季号（`S01`、`Season 1`、`第1季` 等）
   - 集号（`E01`、`EP01`、`第1集` 等）
   - 分辨率（`1080p`、`2160p`、`720p` 等）
3. **判断类型**：
   - 有季/集标记 → 剧集/动漫/综艺/纪录片（按具体内容判断子分类）
   - 无季/集标记、单文件 → 电影
   - 不确定时 → 用 TMDB 搜索辅助判断
4. **创建目录结构** — 在对应分类目录下创建规范的文件夹/Season 目录
5. **移动并重命名** — 使用 `move_file` 将文件移动到新位置并重命名为规范格式
6. **清理** — 原位置空目录移入 `trash/`

---

## ⚠️ 注意事项

- 只处理 `未整理/` 目录下的内容，不要触碰其他分类目录中已整理好的文件
- 如果 TMDB 查询失败或无法确定信息，保留在 `未整理/` 中，留给用户人工处理
- 移动前先用 `get_file_info` 确认源文件存在
- 使用 `tmdb_search` / `tmdb_details` 获取准确的中英文名和年份
