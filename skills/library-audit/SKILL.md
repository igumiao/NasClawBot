# 影视库审查指南

⚠️ **`directory_tree` 是递归工具，没有深度限制。** 对 `/影视` 等大目录调用会一次性返回整个目录树，严重浪费 token。扫描用 `list_directory`，检查存在用 `get_file_info`。

## 审查流程

### 1. 确定范围

根据用户意图确定审查范围：
- 用户指定分类（电影/剧集/动漫/综艺/纪录片）→ 只审查该分类
- 用户指定具体作品 → 只审查该作品
- 用户未指定 → 询问想审查哪个分类，不要默认扫描全部
- 如果库很大，主动建议分批审查

### 2. 扫描本地

**剧集/动漫/综艺/纪录片（有 Season 结构）：**

```
list_directory({root}/剧集)          → 列出所有作品目录
list_directory({root}/剧集/作品名)    → 列出所有 Season 目录
```

从目录名中提取：
- 作品名和年份：`绝命毒师.Breaking.Bad.2008` → 用于 TMDB 匹配
- 已有季号：`Season 01`, `Season 02` → 提取数字 (1, 2, ...)

**电影（单层结构）：**

```
list_directory({root}/电影)  → 列出所有电影目录
```

从目录名提取：中文名、英文名、年份。电影没有 Season 结构，每个目录就是一个电影作品。

### 3. TMDB 对比

**匹配作品：**
- 用英文名 + 年份去 `tmdb_search(query="英文名", media_type="tv")` 搜索
- 如果英文名搜不到或不准确，用中文名搜 `tmdb_search(query="中文名")`
- 模糊匹配时对比年份、类型辅助判断

**剧集对比：**
- `tmdb_details(tmdb_id, media_type="tv")` 获取完整信息
- 关键字段：`seasons[]`（每季的 `season_number`、`episode_count`、`air_date`）、`in_production`、`last_air_date`、`next_episode_to_air`
- 对比：本地 `Season XX` 的编号 vs TMDB `seasons[].season_number`
- 排除特典季（season_number=0），只对比正季

**电影系列检测：**
- 先 `tmdb_search` 找到电影，再 `tmdb_details(tmdb_id, media_type="movie")`
- 检查 `belongs_to_collection` 字段：如有值，说明该电影属于一个系列
- 记录 `collection.name` 和 `collection.id`

### 4. 问题检测

**缺季（剧集）：**
- TMDB 有但本地没有的季 → **缺失**
- 示例：TMDB seasons=[1,2,3,4,5,6,7]，本地=[S01,S02,S04,S06,S07] → 缺 S03、S05
- 注意：TMDB 可能包含尚未播出的季（`air_date` 在未来或为空），标记为"待播出"而非缺失

**等待更新（剧集/动漫）：**
- `in_production=true` → 该剧仍在制作中
- 本地已有全部已播出季 → 无需操作，标记为"已是最新，等待下一季"
- `next_episode_to_air` 有值 → 可预告即将播出的集

**续集空缺（电影）：**
- 一个系列的多部电影应全部在本地存在
- 如果 `belongs_to_collection` 指向同一系列，但本地只有其中一部分 → **续集空缺**
- 示例：本地有 `哈利波特1`、`哈利波特3`，TMDB 显示系列共 8 部 → 推荐补全
- 判断方法：用 `tmdb_search` 搜索系列名，或根据系列编号（`Harry.Potter.1`、`Harry.Potter.2`...）推断

### 5. 生成报告

按以下格式汇总：

```
## 📊 影视库审查报告 — {分类}

### 🔴 缺失季数
| 作品 | 已有季 | 缺失季 |
|------|--------|--------|
| 绝命毒师 | S01-S04 | S05 (最终季) |
| 权力的游戏 | S01,S03,S05 | S02,S04,S06,S07,S08 |

### 🟡 等待更新
| 作品 | 已有季 | 状态 |
|------|--------|------|
| 进击的巨人 | S01-S03 | 最终季 Part 3 待播出 |

### 🟢 续集推荐
| 系列 | 已有 | 缺少 |
|------|------|------|
| 哈利波特 | 1,3,4 | 2,5,6,7,8 |

### ✅ 完整作品 (N 部)
已收录完整，无需操作。
```

- 如果全部完整，直接告知"审查范围内未发现缺失"。
- 如果某个问题特别多（如缺季 > 5），可以建议用户优先补全。

## 要点

- 扫描只碰用户指定的分类，不要遍历整个 `/影视`。
- 对比以 TMDB 为准，本地目录名中的年份用于辅助匹配。
- TMDB 查不到的独立作品（如冷门纪录片），标记为"无法验证"而非缺失。
- 季号只认 `Season XX` 格式（两位数字），忽略其他命名。
- `belongs_to_collection` 是检测电影系列的唯一可靠来源，不要凭目录名猜测系列。
- 报告要简洁、可操作，不要列出 TMDB 返回的所有元数据。
