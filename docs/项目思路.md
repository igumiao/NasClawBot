## 项目名称

初步想法：

> **MediaPilot Agent：面向 NAS 私有媒体库的智能运营助手**

或者：

> **Personal Media Agent：基于长期记忆与任务编排的家庭媒体库智能体**

简历标题可以写：

> **AI Agent 驱动的 NAS 私有媒体库智能管理系统**



定位是：

> **家庭媒体库智能运营 Agent**
>  面向个人 NAS / 私有媒体库的自然语言内容管理、订阅追踪、元数据整理与个性化推荐系统。

也可以叫：

> **Personal Media Agent：基于 NAS 的智能影视媒体库运营助手**

这个定位更适合简历，因为它不只是“下载”，而是覆盖了：

- 自然语言任务理解
- 多工具调用
- 任务规划
- 长期记忆
- 订阅与提醒
- 媒体资产管理
- 异步任务执行
- 人机确认与异常处理

真正遇到的问题其实是：

> 普通用户不会操作 NAS、不会判断版本、不会管理文件、不会订阅更新、不会维护媒体库，但他们有明确的观影需求。

所以项目的产品目标可以定义为：

> 让非技术用户通过自然语言管理和消费家庭媒体库。

比如用户说：

> “我想看最近评分高一点的悬疑电影，最好别太恐怖。”

系统不是简单搜索电影，而是完成一串任务：

1. 理解用户偏好：悬疑、评分高、不太恐怖。
2. 查询影视信息库。
3. 结合用户历史偏好和家庭媒体库已有内容。
4. 推荐几部影片。
5. 询问用户是否加入片单或订阅。
6. 检查本地是否已有。
7. 没有则生成合法来源获取 / 入库任务。
8. 后续完成刮削、重命名、归档、通知。

顾虑 1：使用场景少，似乎不需要多 Agent, 我们这个项目场景下是多Agent还是 单Agent 怎么设计

顾虑 2：过于个人化，不像企业业务， 但也是优势来源于我的真实使用场景 想法：简历上应该抽象为：面向私有内容资产的智能运营系统，

## 目标用户

| 用户        | 需求                                           |
| ----------- | ---------------------------------------------- |
| 家人 / 朋友 | 不懂 NAS，不会搜索，只想用自然语言表达想看什么 |
| 你自己      | 想减少手动搜索、整理、重命名、刮削、追更成本   |
| 高级用户    | 想维护订阅、片单、偏好、媒体库质量             |

## 核心痛点

1. 普通用户不知道如何找到想看的内容。
2. 同一部影视作品存在不同译名、版本、年份，容易混淆。
3. 剧集、番剧、综艺更新需要持续追踪。
4. 媒体文件命名混乱，影响刮削和展示。
5. 推荐系统不了解用户长期偏好。
6. NAS 媒体库对非技术用户不友好。
7. 任务执行失败后缺少自动恢复和解释。



## MVP 目标

> 用户通过自然语言提出观影需求，系统能理解、确认、查询、加入任务，并在完成后通知用户。

------

## MVP 功能范围 （以下为举例 具体情况后期探讨）

### 1. 自然语言影视请求

用户可以说：

- “我想看《沙丘2》”
- “帮我找一下最近比较火的日剧”
- “有没有适合周末看的轻松电影？”
- “我想追《咒术回战》新一季，有更新提醒我”
- “我爸想看成龙以前的动作片，推荐几部”

系统需要识别 ：

| 信息     | 示例                         |
| -------- | ---------------------------- |
| 片名     | 沙丘2                        |
| 影视风格 | 科幻、悬疑、动作、喜剧       |
| 年份     | 2024                         |
| 地区     | 日本、韩国、美国             |
| 影视类别 | 电影，电视剧，综艺，纪录片   |
| 偏好     | 不恐怖、节奏快、评分高       |
| 任务类型 | 推荐、查找、订阅、提醒、整理 |

------

### 2. 影视信息消歧

用户说：

> “我想看老男孩。”

系统应该知道可能有：

- 韩国电影《老男孩》
- 中国筷子兄弟短片 / 电影
- 其他同名作品

所以系统要问：

> “你是想看 2003 年韩国朴赞郁导演的《老男孩》，还是中国版本？”

这个功能很适合体现 Agent 能力，因为它不是简单搜索，而是：

- 识别歧义
- 主动澄清
- 保留上下文
- 再继续执行任务

------

### 3. 媒体库查询

系统需要知道：

- 本地有没有这部影片
- 是否已经刮削完成
- 是否缺字幕
- 是否有重复版本
- 是否有缺集
- 是否已被某个用户订阅

用户问：

> “家里现在有《甄嬛传》吗？”

系统回答：

> “媒体库中已有《甄嬛传》，共 76 集，已完成刮削。当前有 1080P 版本，可以直接观看。”

------

### 4. 订阅与提醒

这是很适合 Agent 的功能。

用户说：

> “以后《海贼王》更新了提醒我。”

系统应该创建一个订阅任务：

| 字段     | 内容                              |
| -------- | --------------------------------- |
| 用户     | 用户 A                            |
| 作品     | 海贼王                            |
| 类型     | 动漫剧集                          |
| 触发条件 | 新集数更新                        |
| 行为     | 提醒 / 自动入库 / 自动整理        |
| 通知方式 | 微信 / Telegram / 邮件 / Web 消息 |

这比单次下载更有产品价值。

------

### 5. 媒体库自动整理

这个功能也很适合展示工程能力。

系统可以处理：

- 文件重命名
- 剧集季数识别
- 刮削失败修复
- 重复资源检测
- 缺集检测
- 字幕匹配
- 元数据补全
- 海报、简介、演员信息补全

用户说：

> “帮我检查一下最近下载的电视剧有没有没刮削成功的。”

系统输出：

> “发现 3 个异常：
>
> 1. 《某某剧》第 4 集命名不规范，无法识别。
> 2. 《某某番》第 2 季缺少第 7 集。
> 3. 《某某电影》存在两个重复版本。”





# 这个项目真正能展示的 Agent 能力

可以重点展示这些能力：

## 1. 意图识别

用户一句话可能对应不同任务：

| 用户输入                 | 实际意图           |
| ------------------------ | ------------------ |
| “最近有什么好看的电影？” | 推荐               |
| “帮我找一下沙丘2”        | 查询 / 入库        |
| “以后更新提醒我”         | 订阅               |
| “这个识别错了”           | 元数据修复         |
| “我爸想看战争片”         | 面向他人偏好的推荐 |
| “有没有不用动脑子的喜剧” | 模糊偏好推荐       |

------

## 2. 任务规划

例如：

> “帮我订阅《凡人修仙传》，以后有新集数自动提醒我，最好有字幕。”

系统任务链：

1. 识别作品。
2. 查询作品元数据。
3. 确认正确条目。
4. 创建订阅。
5. 设置更新检测周期。
6. 设置字幕偏好。
7. 创建通知规则。
8. 返回确认结果。

------

## 3. 工具调用

系统可以调用：

- 影视元数据 API
- 本地媒体库数据库
- NAS 文件系统
- 下载 / 入库任务系统
- 刮削服务
- 通知服务
- 用户记忆系统
- 任务队列

这就是 AI Agent 项目比普通聊天机器人更有价值的地方。

------

## 4. 长期记忆

可以记录：

| 记忆类型 | 示例                       |
| -------- | -------------------------- |
| 类型偏好 | 喜欢悬疑、科幻、日剧       |
| 排雷偏好 | 不喜欢恐怖、血腥、烂尾剧   |
| 观看对象 | 父母喜欢老电影、动作片     |
| 质量偏好 | 偏好 1080P，优先中文字幕   |
| 订阅偏好 | 番剧更新后提醒，不自动入库 |
| 历史行为 | 看过、收藏过、放弃过       |

长期记忆是这个项目的亮点之一。





# 产品路线图

## V1：自然语言媒体请求助手

目标：能用自然语言找片、推荐、查询本地是否已有。

功能：

- 对话入口
- 影视名称识别
- 影视信息查询
- 本地媒体库查询
- 简单推荐
- 人工确认

------

## V2：媒体库整理 Agent

目标：减少你手动管理 NAS 的成本。

功能：

- 自动重命名
- 刮削状态检查
- 缺集检测
- 重复版本检测
- 字幕状态检查
- 异常任务报告

------

## V3：订阅与追更系统

目标：从“用户主动找”变成“系统主动提醒”。

功能：

- 新剧 / 番剧订阅
- 更新提醒
- 缺集补全提醒
- 用户级订阅偏好
- 通知系统

------

## V4：个性化推荐 Agent

目标：基于长期记忆和上下文做推荐。

功能：

- 用户偏好画像
- 观看历史
- 家庭成员画像
- 推荐理由生成
- 不喜欢 / 已看过反馈
- 周末观影推荐

------

## V5：多 Agent 化与自动运维

目标：让系统具备更强自主性。

功能：

- Planner Agent
- Library Agent
- Recommendation Agent
- Subscription Agent
- Error Recovery Agent
- 任务日志与可视化面板
